# Image Data Resource live reassessment

Checked 2026-09-01 because the queue still marked source-level licensing
unverified and left IDR as the next image candidate.

## Current contract

The current study pages publish a JSON-LD `Dataset` object, including an exact
Creative Commons licence URL. For example,
`https://idr.openmicroscopy.org/study/idr0065/json/` reports CC BY 4.0. The IDR
FAQ also says licensing is per study and acknowledges legacy CC BY-NC studies,
so a safe adapter must still reject any study outside an exact allow-list.

The documented anonymous search API works. A query for `Organism = Escherichia
coli` returned image identifiers, project and dataset identifiers, image names,
strain annotations, and thumbnail URLs. IDR's FTP service exposes individual
source files and a study-level `SHASUMS` manifest; single images can therefore
be selected without downloading a complete study.

This makes a fail-closed adapter technically feasible:

- require an exact `idrNNNN` accession and matching study URL;
- read the per-study JSON-LD licence and accept only CC0 or CC BY 4.0;
- resolve one exact API image to its project, dataset, organism and source path;
- verify the source file against the published checksum manifest; and
- reject generic thumbnails when the underlying image cannot be rendered.

## Current-corpus review

The prokaryotic studies found do not provide a defensible structure image:

- `idr0065` (CC BY 4.0, DOI 10.17867/10000131) images *E. coli* cells by phase
  contrast and SeqA-YFP replication foci during a CRISPRi screen. These are
  whole-cell and replication-locus readouts, not direct images of the divisome
  or nucleoid record. The first OMERO image currently reports an unavailable
  pixel buffer and supplies only a 96-by-41 thumbnail, while its raw TIFFs
  remain available through FTP.
- `idr0091` (CC BY 4.0, DOI 10.17867/10000149) images whole *E. coli* cells in
  mother-machine channels during lac induction. It does not depict a current
  structure, and the current IDR page directs OME-Zarr access to BioImage
  Archive `S-BIAD852`, a conversion from `idr0091`.
- `idr0127` (CC BY 4.0, DOI 10.1016/j.cmi.2022.01.021) uses macroscopic
  time-lapse imaging of *Staphylococcus aureus* colony appearance and growth.
  It is phenotype evidence, not cell-structure evidence.

## Decision

Reject IDR for the current corpus. The technical and licensing contract is now
clear enough to implement, but an adopted source needs a valid canary mutation.
Building a generic adapter around a merely related whole-cell image would
weaken the repository's rule that image evidence directly depict the structure.
Reconsider if IDR publishes a prokaryotic study that resolves a structure in a
current record and is not already better served through BioImage Archive.
