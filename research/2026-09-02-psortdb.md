# PSORTdb reassessment and narrow ingestion — 2026-09-02

## Outcome

PSORTdb is adopted as a **CURATE_ONLY** source for one exact experimental
protein example. The 2021 PSORTdb paper says the code and data are available
under MIT and Creative Commons licences, but it does not identify an exact
Creative Commons licence or version for the database. The repository
maintainer explicitly accepted responsibility for source licensing in this
public-works integration. The queue therefore records the terms honestly as
`UNVERIFIED`; it does not pretend that an exact licence was established.

This boundary permits only third-party identifiers and evidence links. It does
not permit copying source descriptions, comments or bulk prose into the corpus,
and it does not use cPSORTdb predictions.

Despite its filename and `text/tab-separated-values` response type, the
downloaded bytes are an Apple binary plist containing a Safari WebArchive. Its
main resource contains an HTML `pre` wrapper around the table. The adapter
does not silently scrape around this defect: it requires the exact artifact
hash, main-resource URL/MIME/UTF-8 fields, HTML envelope, 18-column schema and
11,781-data-row count (11,782 physical lines including the header). Any
upstream change stops the import for review.

## Exact canary and independent checks

The selected ePSORTdb row is the unique Swiss-Prot accession `P14016`, with
gene `cotE`, taxon `224308`, experimental localization `Extracellular`,
secondary localization `Spore outer coat`, PMID `3139490`, and row version
`3.00`. The exact live result is:
<https://db.psort.org/search/results?dataset=e&refseq=P14016&show_adjust=1>.

The adapter separately requires the current UniProt record to remain reviewed,
to resolve `P14016` to CotE in taxon 224308, and to retain the expected protein
name: <https://www.uniprot.org/uniprotkb/P14016/entry>. It also resolves
PMID 3139490 at NCBI and pins its title:
<https://pubmed.ncbi.nlm.nih.gov/3139490/>. The resulting protein example is
added to the existing `coat` component of GO:0043591; the exact strain becomes
a canonical example with the same PMID.
