# CellStructureMech

Knowledge base of microbial cell structures — organelles, envelope layers,
appendages, microcompartments and multi-protein complexes — one
evidence-backed, ontology-grounded YAML record per structure.

Sibling of TraitMech, CultureMech, MediaIngredientMech, CommunityMech,
HabitatMech and ProteinTraitsMech. Scaffolding in progress.
