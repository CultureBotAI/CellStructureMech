Discussions

  • CURATION_TODO (RESOLVED): Keep glycocalyx as a parent class rather than merging capsule and slime-layer records into it. GO:0030112 denotes the broad carbohydrate-rich outer layer, while GO:0042603 restricts capsule to a highly organized glycocalyx and GO:0030114 restricts slime layer to a diffuse, easily removed glycocalyx. The existing capsule and slime-layer records therefore remain narrower sibling subclasses of this parent record.
  • CURATION_TODO (OPEN): Resolve exact source-neutral groundings for the broad glycocalyx extracellular matrix. This broad parent record curates one extracellular-matrix component for the carbohydrate-rich layer while leaving exact glycan, glycoprotein, glycolipid, and peptide-polymer groundings to narrower capsule or slime-layer follow-up.
  • CURATION_TODO (RESOLVED): Acknowledge non-microbial GO:0030112 subclasses while curating microbial glycocalyx examples. GO:0030112 exactly names the broad glycocalyx class that already parents the microbial capsule and slime-layer records, but its current GO children also include vascular endothelial, sperm, platelet, and stereocilium glycocalyces. This first CellStructureMech parent record therefore keeps the exact GO identifier while limiting curated examples and assembly prose to the microbial capsule and slime-layer subclasses.
