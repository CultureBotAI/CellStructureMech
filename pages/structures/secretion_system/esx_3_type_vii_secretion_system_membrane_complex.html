ESX-3 type VII secretion system membrane complex

cellstructuremech:esx_3_type_vii_secretion_system_membrane_complex · SECRETION_SYSTEM · MULTIPROTEIN_COMPLEX · PROPOSED

A Mycobacterium smegmatis ESX-3 type VII secretion inner-membrane core complex in which EccB3, EccC3, EccD3, and EccE3 assemble into a dimeric membrane-embedded secretion machine. [DOI:10.1038/s41586-019-1633-1]

Synonyms: ESX-3 core complex; ESX-3/Type VII secretion system
