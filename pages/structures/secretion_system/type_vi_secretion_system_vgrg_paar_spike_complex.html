type VI secretion system VgrG/PAAR spike complex

cellstructuremech:type_vi_secretion_system_vgrg_paar_spike_complex · SECRETION_SYSTEM · MULTIPROTEIN_COMPLEX · PROPOSED

A bacterial type VI secretion system tip subassembly in which trimeric VgrG proteins cap the Hcp tube and associate with PAAR-repeat proteins to sharpen the puncturing spike. [DOI:10.1128/microbiolspec.PSIB-0031-2019]

Synonyms: T6SS VgrG/PAAR spike complex; VgrG/PAAR spike; type VI secretion system spike

Part of: GO:0033104
