type VI protein secretion system complex

GO:0033104 · Secretion system · Multiprotein complex · Proposed

A bacterial contractile injection machine whose envelope-spanning membrane complex anchors a baseplate and sheath-wrapped Hcp tube; sheath contraction propels the Hcp/VgrG/PAAR spike and associated effectors out of the cell into target cells. [GO:0033104]

Synonyms: T6SS complex; type VI secretion system

Has part: type VI secretion system baseplate (cellstructuremech:type_vi_secretion_system_baseplate); type VI secretion system contractile sheath (cellstructuremech:type_vi_secretion_system_contractile_sheath); type VI secretion system membrane complex (cellstructuremech:type_vi_secretion_system_membrane_complex); type VI secretion system Hcp tube (cellstructuremech:type_vi_secretion_system_hcp_tube); type VI secretion system VgrG/PAAR spike complex (cellstructuremech:type_vi_secretion_system_vgrg_paar_spike_complex)

Mechanism graphs

A baseplate-primed sheath ejects an Hcp tube and VgrG spike (FUNCTION)

The TssJLM membrane complex recruits a phage-like baseplate. The baseplate primes Hcp tube polymerization and TssB/TssC sheath extension; when the sheath contracts, it ejects the Hcp-VgrG-PAAR spike and any associated effectors through the envelope into a target cell.
