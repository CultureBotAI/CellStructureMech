cyanelle thylakoid

GO:0009843 · Membrane organelle · Membrane bounded organelle · Proposed

A thylakoid found in a cyanelle, which is a type of plastid found in certain algae. The cyanelle contains a photosynthetic membrane resembling that of cyanobacteria. [GO:0009843]

Part of: cyanelle (GO:0009842)

Has part: cyanelle thylakoid lumen (GO:0033114); cyanelle thylakoid membrane (GO:0033115)

Xrefs: uniprot.location:SL-0277 — Cyanelle thylakoid
